# 💻 IT Destek Talep Sistemi

Tuzla Belediyesi Bilgi İşlem Müdürlüğü stajım kapsamında geliştirdiğim web tabanlı destek talep yönetim sistemidir.

Sistem sayesinde kurum çalışanları teknik sorunlarını kayıt altına alabilir, taleplerini takip edebilir ve IT birimi talepleri merkezi olarak yönetebilir.

## Özellikler

- Kullanıcı girişi ve oturum yönetimi
- Destek talebi oluşturma
- Talep öncelik belirleme
- Talep durum takibi
- Talep güncelleme
- Rol bazlı yetkilendirme
- Yönetici paneli
- SQLite veritabanı entegrasyonu

  ## Kullanılan Teknolojiler

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- Razor Pages
- HTML5
- CSS3
- Bootstrap
- LINQ

  ## Proje Mimarisi

Proje MVC (Model-View-Controller) mimarisi kullanılarak geliştirilmiştir.

- Models: Veri yapıları
- Views: Kullanıcı arayüzleri
- Controllers: İş mantığı
- Entity Framework Core: Veritabanı işlemleri
- SQLite: Veri depolama

  ## Kazanımlar

Bu proje kapsamında:

- ASP.NET Core MVC yapısını uygulamalı olarak kullandım.
- Entity Framework Core ile veritabanı işlemleri gerçekleştirdim.
- SQLite veritabanı tasarladım ve yönettim.
- Rol bazlı yetkilendirme yapısını uyguladım.
- Web uygulamalarında CRUD operasyonları geliştirdim.
- Kurumsal iş süreçlerini analiz ederek yazılım çözümüne dönüştürdüm.
